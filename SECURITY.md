# Política de Segurança

Levamos a segurança e a privacidade das informações financeiras muito a sério. Este documento descreve as políticas de segurança e o processo para reportar possíveis vulnerabilidades.

## Versões Suportadas

Atualmente, apenas a versão mais recente em execução no branch `principal` recebe atualizações e correções de segurança.

| Versão | Suportada |
| :--- | :--- |
| 1.x (Atual) | :white_check_mark: |
| < 1.0 | :x: |

## Como Reportar uma Vulnerabilidade

Se você identificar uma falha de segurança, vulnerabilidade ou vazamento de dados neste projeto:

1. **Não abra uma Issue pública.**
2. Entre em contato diretamente abrindo um aviso privado de segurança pela aba **Segurança (Security) > Report a vulnerability** no GitHub.
3. Descreva os detalhes da vulnerabilidade, os passos para reproduzi-la e o impacto potencial.

---

### Boas Práticas de Uso
* Nunca compartilhe publicamente credenciais de acesso ou URLs de implantação do Google Apps Script com permissões de gravação irrestritas.
* Mantenha os links da API protegidos e restritos ao uso das pessoas autorizadas.
